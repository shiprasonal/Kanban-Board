# 📋 Kanban Board

An interactive task management application built using **HTML, CSS, and JavaScript**. It helps users organize tasks, manage daily activities, and track task progress through a simple and intuitive Kanban board interface.

## ✨ Features

* Add new tasks to the board.
* Organize tasks into different columns based on their status.
* Move tasks between columns to track progress.
* Edit and delete existing tasks.
* Dynamic task updates using JavaScript.
* Clean and user-friendly interface.
* Responsive design for different screen sizes.

## 🛠️ Tech Stack

| Technology | Purpose                              |
| ---------- | ------------------------------------ |
| HTML5      | Structure and layout                 |
| CSS3       | Styling and responsive design        |
| JavaScript | Task management and DOM manipulation |

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/shiprasonal/Kanban-Board.git
```

**2. Navigate to the project folder**

```bash
cd Kanban-Board
```

**3. Run the application**

Open `index.html` in your preferred web browser.
